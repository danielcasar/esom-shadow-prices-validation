## Data

### ENTSO-E day-ahead prices

Downloaded via the [ENTSO-E Transparency Platform API](https://transparency.entsoe.eu/).
Requires a free API token (register at the platform, then request access).

```bash
cp .env.example .env          # then open .env and paste your token
python paper/scripts/import_entsoe_prices.py
```

This writes `data/ENTSOE_day_ahead_prices.csv` (hourly day-ahead prices for 22
European countries, 2018–2025). If the file already exists, `run_all.py` skips
this step automatically.

### GENeSYS-MOD model output

`data/GENeSYS_MOD_prices.csv` contains hourly dual prices from the
[GENeSYS-MOD](https://github.com/GENeSYS-MOD/GENeSYS_MOD.jl) energy system model
for 22 European countries, 3 snapshot years (2018, 2025, 2030), and 4 scenarios
(GoRES, NECPEssentials, REPowerEU++, Trinity).

This file is the deterministic output of running an open-source model with
publicly documented scenario inputs:

- **Model**: [GENeSYS-MOD](https://github.com/GENeSYS-MOD/GENeSYS_MOD.jl) — open-source, see Löffler et al. (2017).
- **Scenario inputs**: European Energy Vision 2060 (EnVis-2060) — see Barani et al. (2025).
- **Consolidation**: `paper/scripts/merge_genesys_data.py` consolidates the raw per-run GENeSYS-MOD
  output into the single hourly CSV the rest of the pipeline ingests.

To regenerate the file, run GENeSYS-MOD with the EnVis-2060 scenario inputs for the four scenarios and three snapshot years above, then run `merge_genesys_data.py` against the resulting raw outputs. The merged CSV is not redistributed here because the underlying scenario assumptions are not the authors' to publish.

Place the resulting `GENeSYS_MOD_prices.csv` at `data/GENeSYS_MOD_prices.csv` before running the rest of the pipeline.

Expected columns: `year`, `scenario`, `Hour` (1–8760), plus one column per country
(ISO-2 codes: AT, BE, BG, CH, CZ, DE, EE, ES, FI, FR, GR, HR, HU, IE, LT, LV, NL,
PL, PT, RO, SI, SK) with hourly dual prices in €/MWh.

## Reproduction

Once both data files are in place, reproduce all results and figures with:

```bash
python paper/scripts/run_all.py
```

Expected runtime: ~15–30 minutes (dominated by the data import and Stage 2 t-tests).

analysis; all scripts import from it.
